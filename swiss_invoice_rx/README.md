# Swiss-invoice-RX

Home-Assistant-App für die lokale Verwaltung von Schweizer Rechnungen und Geschäftsdaten.

**Enthalten:** Rechnungen mit QR-Zahlteil, Kunden, Inventar, Zahlungen, Vorlagen, PDF-Designer und getrennte Benutzerrechte für mehrere Geschäfte.

Die App ist über Home Assistant Ingress sowie optional über einen lokalen Netzwerkport erreichbar. Die Daten werden im persistenten App-Verzeichnis gespeichert.
