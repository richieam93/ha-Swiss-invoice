# Version 2.9.0 – Eigene Geschäftsverwaltung

Die Option **„Eigenes Geschäft erstellen“** wird bei der Benutzeranlage korrekt übernommen.

- Erstlogin ohne Zugriff auf bestehende Geschäftsbereiche
- Geführte Einrichtung einer eigenständigen Geschäftsumgebung
- Vollständige Verwaltungsrechte nur für das eigene Geschäft
- Vorhandene Einzelzuordnungen können über **„Eigenes Geschäft einrichten lassen“** aufgehoben werden.

Bestehende Rechnungen und Geschäftsdaten werden dabei weder übertragen noch gelöscht.
