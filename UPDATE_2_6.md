# Version 2.6.0 – Eigene Geschäftseinrichtung

- Benutzer können ohne bestehende Geschäftszuordnung eingeladen werden.
- Geführte Einrichtung für Geschäftsart, Adresse, Logo, Passwort und Zahlungsdaten
- Unabhängige MWST-Einstellungen; nachträglich unter **Firmendaten** änderbar
- Volle Geschäftsleitungsrechte ausschliesslich für das neu angelegte Geschäft
- Offene Einladungen können widerrufen werden.
